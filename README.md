# Tripleten web_project_around_es

## Descripción

Página web que muestra el perfil de un usuario y una galería de lugares.

## Funcionalidad

- Editar perfil, agregar y eliminar tarjetas, dar "me gusta", ampliar imágenes, cerrar modales con tecla esc o click fuera de estos.

## Tecnologías

HTML5, CSS3 (BEM, Flexbox, Grid) y JavaScript.
